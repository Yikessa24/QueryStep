# LLM 多轮辅导

单 Agent 使用当前主题、提示阶段和最近五轮同题问答。原创题可附审核提示。普通提问可调用课程资料和审核例题工具，并选择追问、提示、示例或邀请继续练习。服务端校验工具参数、引用和调用预算，超时或输出校验失败时使用审核模板。判分与下一题决策由各自服务负责。

学生明确回指某个轮次时，后端先判断这轮是否已在窗口内。窗口内的问答可以直接引用。窗口外的轮次通过只读工具 `retrieve_tutor_history` 回查，每次返回一轮。工具只接收 `turn_number`，后端从当前学习者、当前作答的已授权历史取数据。回查结果进入本次模型上下文，页面显示通过校验的轮次引用，工具执行可在 API 响应的 `trace` 中核对。每题仍最多八轮，单条提问仍最多三次模型调用、两次工具调用。

映射到研究数据的题目默认使用审核提示。确认学生自由文本可发给所选模型供应商后，部署者可用 `QUERYSTEP_LLM_ALLOW_MAPPED_ITEMS=1` 开启。该路径只提供主题和经筛查的对话，不附题干、选项、答案键、作答历史或映射 ID。

服务配置、合成探针和出错回退见 [操作指南](../deploy/OPERATIONS.md)。`python -m tutor.check_provider` 会用同一传输适配器检查模型列表、函数调用、结构化响应和两轮辅导。

## 五轮窗口验收

使用同一个真实 Gemini 配置和合成果篮问答，两种窗口均启用指定轮次回查。每格运行一次，均引用第 1 轮并返回两个预期数值。用量是该次提问所有模型调用的输入 token 总和，耗时包含模型往返。

| 回指第 1 轮时已有的问答 | 三轮窗口 | 五轮窗口 |
|---|---|---|
| 已有 5 轮 | 2 次调用，1156 token，18.13 秒 | 1 次调用，610 token，6.41 秒 |
| 已有 7 轮 | 2 次调用，1156 token，12.31 秒 | 2 次调用，1288 token，15.99 秒 |

在这组样本中，五轮窗口能让较早的问答直接进入模型，但窗口之外的回指仍需额外一轮模型调用。单次时延易受上游波动影响。这组结果用于验证两条路径的行为。
