# LLM 多轮辅导

单 Agent 使用当前主题、提示阶段和至多两轮对话。原创题可附审核提示。可调用课程资料与审核例题两个只读工具，并选择追问、提示、示例或邀请继续练习。服务端校验工具参数、引用和调用预算，超时或输出校验失败时使用审核模板。判分与下一题决策由各自服务负责。

映射到研究数据的题目默认使用审核提示。确认学生自由文本可发给所选模型供应商后，部署者可用 `QUERYSTEP_LLM_ALLOW_MAPPED_ITEMS=1` 开启。该路径只提供主题和经筛查的对话，不附题干、选项、答案键、作答历史或映射 ID。

服务配置、合成探针和出错回退见 [操作指南](../deploy/OPERATIONS.md)。`python -m tutor.check_provider` 会用同一传输适配器检查模型列表、函数调用、结构化响应和两轮辅导。
