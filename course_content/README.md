# 学生题库

保存原创或获准展示的 SQL 题目、选项、课程资料和审核例题。每题需要稳定 ID、内容版本、题干、选项、唯一正确选项、难度、KC 映射和来源许可。答案键只留在判分服务。DBE-KT22 原始内容归入 data，按其使用协议单独管理。

内部导入保留题目富文本的换行，并逐题核对可见文字与普通文本。富文本与普通文本不一致时，导入会指出需要审阅的题号。审阅时核对题目可独立理解、选项和答案、难度、提示、题号与有序 KC，以及学生展示的适用范围。

获准展示的题库可用 `python -m course_content.check_catalog --run RUN目录 --catalog 题库JSON` 核对模型词表和训练覆盖。预检可在 CPU 上运行，输出不含题干、选项和答案。预检通过仍需实际加载和推荐验收。

生成获准的学生演示题库时可传 `--demo-context`。选项、正确选项、题号和有序 KC 均保留。依赖数据库实例的题会附上标为合成的表行，逐题 SQL 结果由 `tests/test_dbe_demo_context.py` 校验。
